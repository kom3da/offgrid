使い方

何をする道具か

今日やることを1つずつ出して、進み具合を覚えておく道具。答えは出さない。自分で手を動かして気づくのが目的だから。

3つだけ覚える

  1. いまやることを開く。上から順に、書かれたとおりに手を動かす
  2. コマンドは自分のターミナルで打つ（この画面では打てない）。画面のコマンドは、クリックでコピーできる
  3. できたら「できた」。分からなければ「手がかり」。止まったら「詰まった」

ボタンの意味

  • できた：その課題を済みにして、次の課題を出す
  • あとで：飛ばす。その枠の最後に、もう一度出てくる
  • 手がかり：キーワード、詰まりやすいところ、読む本の場所を出す（答えは出ない）
  • 詰まった：何が起きたかを1行書くと、振り返りの「詰まったこと」に時刻付きで入る。次のセッションの前に、AIと一緒に解消する
  • この枠を終える：残りの課題を次回に回して、次の枠へ進む

時間の見かた

同じ課題に15分たつと、手順を切り替えるよう促す（エラー文を全文読む → man → 最小の再現 → 検索）。45分で打ち切りを促す。止まったまま座っているのが、いちばん損だから。

書いたものは、どこに入るか

  • 課題のチェック：そのユニットの work.md
  • メモ：そのユニットの notes.md（この画面からも足せる）
  • 振り返りと詰まりメモ：logs/<年>/<月-日>.md
  • ユニットの完了：PROGRESS.md

全部ふつうのテキストファイル。あとから自分で直してよい。この道具が無くても読める。

ターミナルだけで使いたいとき

offgrid run で、同じ案内がターミナルで動く。状態は共有しているので、途中で行き来してよい。

止めかた

この画面を立てたターミナルで Ctrl+C。ネットワークにもAIにもつながっていないので、切っても何も壊れない。
