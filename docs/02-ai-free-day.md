---
title: "AIなしデーの運用"
---

AIなしデーは「閉域の現場で1日働く」想定の訓練日。道具を制限し、時間を区切り、必ず記録を残す。

## ルール

- AI補完（Copilot等）とAIチャットはすべてオフ。エディタのAI拡張も無効化する
- 使ってよいもの：`man`、`--help`、`go doc`、`pkgsite`（ローカル）、公式ドキュメントのオフラインコピー、書籍、自分の過去のメモ
- Web検索の上限は、Stage 0〜2は1日5回、Stage 3は3回、Stage 4〜5は0回。検索したら内容を振り返りメモに記録する
- 詰まったら、下の「詰まったときの手順」に切り替える
- コードと記録はすべてこのリポジトリにコミットする（コミット規約は README 参照）

## 詰まったときの手順

閉域の現場には「翌日のAI」はいない。自力で抜け出す手順そのものを練習する。15分進まなかったら、次の順に試す。

1. エラーメッセージを最後まで読み、分からない単語に印を付ける
2. `man`、`--help`、`go doc`、オフラインのドキュメントで、その単語を調べる
3. 問題が起きる最小のコードやコマンドを、別ファイルに切り出して再現する
4. Web検索を使う（上限内で。検索語と分かったことを記録する）

合計45分たっても抜け出せなければ打ち切り、「詰まりメモ」に書いて、同じユニットの別の小課題に進む。詰まりメモは、翌平日にAIと一緒に解消する。

## 1日のテンプレート（6時間）

| 時間 | ブロック | 内容 |
| --- | --- | --- |
| 9:00–9:30 | ウォームアップ | 再現ドリルを1本と、平日のレビューで指摘された箇所の直しを1件（下記） |
| 9:30–12:00 | メイン① | 今のステージのユニット。最初の30分は、そのユニットの読書に充ててよい。最後の10分で、午前の詰まりを記録する |
| 13:00–14:00 | メイン② | メイン①の続き。Stage 1〜2は、この1時間をPostgreSQLに充てる |
| 14:00–15:30 | コードリーディング／デバッグドリル | 1回おきに交代する。リーディングは読解課題を1本、デバッグは仕込みバグを3つ |
| 15:30–16:00 | 振り返り | テンプレートに沿って記録、次回のユニットを決める |

新しいことを学ぶ時間（メイン①②）は、Stage 0とStage 3〜5で3.5時間、Stage 1〜2でGo・TSが2.5時間＋PostgreSQLが1時間になる。

## ウォームアップ：再現ドリル

過去にやった内容を、何も見ずに再現する。Stage 0ではコマンド操作（例：ログから上位10件を出すパイプライン）、Stage 1以降は自分が書いた30〜50行の関数。

- 1回に1本だけ。前回の内容と、4回以上前の内容を、1回おきに交互に選ぶ。忘れかけた頃に思い出すほうが、記憶に残りやすい
- 課題シートに「次回のウォームアップでもう一度」とあるものは、その回の1本として扱う
- 30分に収まらない分は、次回に回す。ウォームアップを延ばして、メインの時間を削らない
- 再現率は「元のテストが通ったか」と「途中で何回、元のコードを見たか」で記録する
- 再現できなかった箇所が、今の弱点

## ステージごとの午後の中身

| ステージ | コードリーディング枠 | デバッグ枠 |
| --- | --- | --- |
| Stage 0 | manページ（`man ls`、`man grep`など短いもの）や設定ファイルを読む | 壊れたシェルスクリプト、Gitのコンフリクトを直す |
| Stage 1〜2 | 自分の過去のコード、Go標準ライブラリの短い関数、小さなOSS | 仕込みバグのGo・TSコードを直す |
| Stage 3〜5 | 中規模OSS、自分がAIで書いた過去のコード | 並行処理・SQL・運用のバグを直す。月に1回はTypeScriptのバグも入れる |

## 平日の補助メニュー（30分）

- 月：AIなしデーの `[no-ai]` コミットのレビューをAIに頼み、指摘を読む（直すのは次回のウォームアップで、自分の手で）。詰まりメモも、AIと一緒に解消する（`prompts/weekly-review.md`）
- 火：読書（今のユニットに対応する章。[教材](11-resources.md)を参照）
- 水：`explain.md` を書いた週は、AIに採点を頼む（`prompts/grade-explain.md`、[評価基準](10-evaluation.md)）。次回がデバッグドリルの回なら、AIに問題を作らせる（答えは `answers/` に置き、見ない）
- 木：読書
- 金：翌日のAIなしデーの準備（ユニットの確認、依存やオフライン用ドキュメントの取得）

## 段階的な導入

最初の3回は12:00まで（3時間）、4〜6回目は14:00まで（4時間）、7回目からフル6時間にする。短縮の回は、最後の30分を振り返りに充てる。

## 時間がない週の最小メニュー

ウォームアップとメイン①だけ（9:00–12:00の3時間）でも、1回と数えてよい。2週以上空いたときは、新しいユニットに進む前に、再現ドリルを2本やってから再開する。ペースが落ちても、振り返りだけは続ける。
