## ねらい

コンピュータの中では、数も文字もすべて「バイトの並び」であることを、自分の目で確かめる。

## 平日に読むもの

『コンピュータはなぜ動くのか』の、2進数・文字コード・CPUとメモリを扱う章。

## 準備

```sh
mkdir -p ~/sandbox/f01 && cd ~/sandbox/f01
```

## 課題

分からないコマンドは、まず `man コマンド名` か `コマンド名 --help` で調べる。

1. 10進数の 5、10、255、256 を、紙の上で2進数と16進数に直す。そのあと `printf '%x\n' 255` や `echo $((2#1010))`、`echo $((16#ff))` で答え合わせをする
2. `printf 'A' | xxd` を実行する。出力は左・中央・右の3つの部分に分かれている。それぞれが何を表すかを `man xxd` で調べて、メモに書く
3. `A`、`a`、`0`（数字のゼロ）、空白、改行のバイトの値を `xxd` で調べ、表にする。`echo 'A' | xxd` と `printf 'A' | xxd` の出力は何が違うか。なぜ違うか
4. `printf 'あ' | xxd` を実行する。「あ」は何バイトか。`printf 'aあ😀' | xxd` では、それぞれの文字が何バイトになっているか。`wc -c` と `wc -m` の結果を比べて確かめる
5. `xxd -b` で、課題4のバイトを2進数で表示する。各文字の1バイト目の先頭のビットの並びと、その文字のバイト数の間に、どんな規則があるかを見つける
6. `head -c 1000 /dev/zero > zero.bin` でファイルを作る。`ls -l` のサイズ、`wc -c` の結果、`xxd zero.bin | tail -3` の出力を見比べる。`/dev/zero` とは何か
7. `lscpu`、`free -h`、`df -h` を実行し、自分の環境のCPUの数、メモリの量、ストレージの空きを読み取る。CPU・メモリ・ストレージの役割を、それぞれ1文で書く。メモリとストレージは、電源を切ったときと速さの点で、どう違うか
8. `file /bin/ls` と `file zero.bin`、自分で作ったテキストファイルに対する `file` の結果を比べる。`xxd /bin/ls | head -1` の先頭4バイトは何を意味するか
