# F2：シェル入門（課題シート）

この `README.md` は書き換えない。自分が書いたものは、同じディレクトリに別のファイルとして置く。

## ねらい

マウスを使わずに、ファイルとディレクトリを自由に扱えるようになる。

## 平日に読むもの

『新しいLinuxの教科書』の、シェルの基本、ファイル操作、パーミッションを扱う章。

## 準備

```sh
mkdir -p ~/sandbox/f02 && cd ~/sandbox/f02
```

## 課題

1. `pwd`、`ls`、`ls -la`、`cd` を試す。`~`、`.`、`..`、`/` がそれぞれ何を指すかを、実際に `cd` して確かめ、メモに書く
2. `mkdir -p` を使い、`project/src`、`project/docs/img`、`project/tmp` を作る。`find project` で、できあがった構造を表示する
3. `project/src` に空のファイルを3つ作る（`touch`）。1つをコピーし、1つの名前を変え、1つを `project/tmp` に移動し、最後に `project/tmp` をディレクトリごと消す。`rm -r` がなぜ危険かを書く。`rm -i` は何をするか
4. 同じファイルを、絶対パスと相対パスの両方で `ls -l` する。`cd` で別の場所に移動したあと、もう一度両方を試す。結果が変わるのはどちらか
5. `*.txt` や `file?.txt` のようなワイルドカードで、複数のファイルをまとめて `ls` する。`echo *.txt` を実行すると何が起きるか。そこから、ワイルドカードを展開しているのは誰だと言えるか
6. `ls -l` の各列の意味を調べる。`rwxr-xr-x` を数字に直す。ファイルを作り、`chmod` で `644`、`600`、`755`、`u+x`、`go-r` を順に試し、そのたびに `ls -l` で確かめる
7. 中身が `echo hello` だけのファイル `hello.sh` を作る。`./hello.sh` で実行しようとすると何が起きるか。実行できるようにする
8. `find ~/sandbox -name '*.txt'`、`-type d`、`-newer` を試す
9. `man ls` を読み、「サイズの大きい順」「更新の新しい順」「人が読みやすい単位で」の表示方法を見つける
10. 仕上げ：課題2〜7と同じ操作を、自分で10個の指示リストにして `checklist.md` に書く。次回のウォームアップで、何も見ずにその10個をこなす
