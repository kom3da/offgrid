# F5：シェルスクリプト（課題シート）

この `README.md` は書き換えない。自分が書いたスクリプトは、同じディレクトリに置く。

## ねらい

手で打っていたコマンドの並びを、失敗したらきちんと止まるスクリプトにできるようになる。

## 平日に読むもの

『新しいLinuxの教科書』のシェルスクリプトを扱う章。

## 準備

スクリプトは、このディレクトリ（`drills/foundation/F05-script/`）に書く。試しに動かす対象は `~/sandbox/f05` に作る。

## 課題

小さなスクリプトを1つずつ書く。書くたびに `shellcheck ファイル名` にかけ、指摘をすべて読む。

1. `hello.sh`：1行目の `#!/usr/bin/env bash` は何のためにあるか。`./hello.sh` と `bash hello.sh` の違いは何か
2. `quote.sh`：空白を含むファイル名（`my file.txt`）を変数に入れ、`ls -l $f` と `ls -l "$f"` の違いを確かめる。`'` と `"` の違いも確かめる
3. `args.sh`：引数の数（`$#`）と、すべての引数（`"$@"`）を1行ずつ表示する。引数が1つもなければ、使い方を標準エラーに出して、終了コード1で終わる
4. `check.sh`：引数で受けたパスが、ファイルか、ディレクトリか、存在しないかを表示する（`[ -f ]`、`[ -d ]`）。数の比較（`-eq`、`-gt`）と文字列の比較（`=`、`-z`）も試す
5. `loop.sh`：カレントディレクトリの `*.txt` を1つずつ処理する `for`。`{1..5}` の連番。`while read -r line` で、ファイルを1行ずつ読む
6. `func.sh`：メッセージを標準エラーに出して終了する関数 `die` を作り、使う
7. `strict.sh`：`set -euo pipefail` の3つを1つずつ外し、次の場面で動きがどう変わるかを確かめて、表にする
   - 定義していない変数を使った
   - 途中のコマンドが失敗した
   - パイプの途中のコマンドが失敗した
8. **本題** `backup.sh`：引数で受けたディレクトリを、`backup/<ディレクトリ名>-<日付と時刻>` にコピーする。次の場合にも、正しく動くこと
   - 引数がない → 使い方を出して終了コード1
   - ディレクトリが存在しない → エラーを標準エラーに出して終了コード1
   - ディレクトリ名に空白が含まれる
9. 応用：`backup.sh` に、7日より古いバックアップを消す機能を足す（`find -mtime`）。実際には消さずに、消す対象だけを表示するオプションも付ける

## 完了条件の確かめ方

- `backup.sh` に対する `shellcheck` の指摘がゼロ
- 課題8の3つの場合を実際に試し、結果と終了コード（`echo $?`）を `notes.md` に貼ってある

## 残すもの

各スクリプト、`notes.md`（課題7の表を含む）。
