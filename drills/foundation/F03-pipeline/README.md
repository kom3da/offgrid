## ねらい

小さなコマンドをパイプでつなぎ、ログから欲しい情報を取り出せるようになる。閉域の現場で、いちばん使う技術。

## 平日に読むもの

『新しいLinuxの教科書』の、標準入出力とパイプ、テキスト処理、正規表現を扱う章。

## 準備

ダミーのアクセスログを作る（IPアドレスは例示用の範囲で、実在しない）。

```sh
mkdir -p ~/sandbox/f03
cd ~/offgrid-log
./scripts/gen-access-log.sh > ~/sandbox/f03/access.log
cd ~/sandbox/f03
```

## 課題

1. `wc -l`、`head`、`tail`、`less` でログを眺める。`less` の中で、文字列の検索と終了のしかたを調べる。ログの1行は、空白で区切るといくつの部分に分かれるか。それぞれが何を表すか
2. `grep` で、ステータスコードが404の行だけを表示する。その行数を数える。`-c`、`-v`、`-i`、`-n` のオプションを、それぞれ試す
3. `cut` を使って、IPアドレスの列だけを取り出す。同じことを `awk` でもやる。ステータスコードの列だけを取り出す
4. IPアドレスの列に対して、`uniq` だけを使った場合と、`sort` してから `uniq` した場合の行数を比べる。なぜ違うか。`uniq -c`、`sort -n`、`sort -r` を試す
5. `>`、`>>`、`2>`、`<`、`|` の違いを、それぞれ実際に試して書く。存在しないファイルを `cat` したときの、エラーメッセージだけをファイルに保存する
6. **本題**：アクセス数が多いIPアドレスの上位10件を、件数つきで、1行のコマンドで表示する
7. 応用：同じ考え方で、次の3つを出す
   - ステータスコードごとの件数
   - 404になったパスの上位5件
   - 時間帯（時）ごとのアクセス数
8. 正規表現（文字列のパターンを表す書き方）：`.`、`*`、`+`、`[ ]`、`^`、`$` の意味を表にまとめる。`grep -E` で、次の行を取り出す
   - `192.0.2.` で始まる行
   - パスが `/items/数字` の行
   - ステータスコードが500番台の行
9. `sed` で、IPアドレスの最後の数字を `xxx` に置き換えて表示する。`sed -n` で、10行目から20行目だけを表示する。`awk` で、ステータスコードが500以上の行の、IPアドレスとパスだけを表示する。`awk` で、転送バイト数の合計を出す
10. `find` と `xargs` を組み合わせて、`~/sandbox` の下にあるすべての `.log` ファイルの行数を数える
