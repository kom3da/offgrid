# 週次レビューのプロンプト（月曜）

AIなしデーの翌平日に、Claude Code を学習用リポジトリで開いて渡す。レビューの方針は `CLAUDE.md` に書いてあるので、頼む文面は短くてよい。

```text
前回のAIなしデー（タグ noai-YYYY-MM-DD）の [no-ai] コミットをレビューしてください。
CLAUDE.md の「レビューの方針」と「学習を奪わない」ルールに従ってください。
- PROGRESS.md で今のステージとユニットを確認し、未学習の知識を前提にしないこと
- 修正コードは書かず、指摘とヒント（弱いものから）だけにすること
- 最後に「次に練習すべきこと」を1〜3個挙げること
続けて、logs/ の最新の振り返りにある「詰まったこと」を、一緒に解消させてください。答えを先に言わず、私に質問しながら進めてください。
```

指摘を読んだら、直すのは次回のウォームアップで、自分の手で行う。
