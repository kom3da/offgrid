title: "改訂プロンプト（Claude Code 向け）"
---

```text
offgrid の改訂作業を手伝ってください。docs/30-revision.md の「定期点検で確かめること」に沿って進めます。

1. docs/ 配下を読み、次の観点で「古くなっている可能性がある箇所」を一覧にしてください。
   - Go / Node.js / PostgreSQL / Docker のバージョンに依存する記述
   - 書籍の版・絶版、Web教材のURL変更
   - ツールの廃止・置き換え（静的解析、負荷試験、ローカルLLM、グラフライブラリ）
   - オフライン化手順の変更
2. 各項目について、記憶ではなく検索で現行状況を確認し、根拠となるURLを添えてください。
3. 変更案を「ファイル名・現在の記述・変更案・理由」の表にまとめてください。
4. docs/ の書き換えは、私が採用する項目を選んでから行ってください。
5. 採用した変更を CHANGELOG.md に、版（vYYYY.MM。同じ月の2回目以降は vYYYY.MM.N）の見出しで追記してください。

改訂は、学習テキストとしての内容を直す作業です。誰かの学習の進み具合（PROGRESS.md、logs/）は、改訂の材料にしないでください。
GitHub の Issue に報告があれば、それも一覧に含めてください。
```
